# E-Commerce-Store-Database-System
Project Overview
A complete database solution for an e-commerce store, featuring product management, customer profiles, and order processing.

Key Features
⦁	Normalized Schema: Designed for data integrity and efficiency.
⦁	CRUD Operations: Full support for customer and admin roles.
⦁	Business Logic: Includes CHECK constraints and complex relationships.
