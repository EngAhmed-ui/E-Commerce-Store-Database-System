# 🛒 E-Commerce Store Database System
**Solo Project** | **Language:** SQL, PHP

## 📌 Project Overview
A complete database solution for an e-commerce store, featuring product management, customer profiles, and order processing. This system was designed to handle the core business needs of a digital storefront, ensuring data integrity and a seamless user experience.

## 🚀 Key Features
* **Normalized Schema:** Designed for data integrity and efficiency, minimizing redundancy across 15+ related tables.
* **CRUD Operations:** Full support for customer roles (browsing, ordering) and admin roles (inventory and order management).
* **Advanced Business Logic:** Implementation of `CHECK` constraints, foreign keys, and complex relationships to enforce business rules directly at the database level.
* **PHP Integration:** A vanilla PHP application structure used to bridge the SQL backend with a functional user interface.
